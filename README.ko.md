**Tidy는 갤럭시 앱스 화면을 One UI 그대로 폴더로 정리해 줘요.**
새 런처에 적응할 필요 없어요. Tidy가 진짜 One UI 앱스 화면에서, 손으로 하듯이
아이콘을 폴더에 넣어 줘요.

- **기존 폴더 유지**: 폴더 밖 앱만 알맞은 폴더에 넣고, 만들어 둔 폴더는 그대로 둬요
- **Tidy에 맡기기**: 지금 폴더는 무시하고 모든 앱을 처음부터 정리해요
- **미리보기 먼저**: 바뀌는 점을 다 보여주고, 앱을 다른 폴더로 옮기거나 폴더 이름을 바꾼 뒤에 적용해요. 되돌리기도 돼요
- **새 앱**: 새로 설치한 앱을 맞는 폴더에 넣을지 물어보거나 바로 넣어 줘요
- **국내 앱도 잘 알아요**: 토스, 배민, 카카오톡 같은 앱과 삼성 기본 앱까지
- **폰 안에서만 처리**: 앱 목록은 어디에도 전송되지 않아요
- **한국어·영어**, 폰 언어를 따라가요

One UI 홈을 쓰는 갤럭시 폰과 접근성 권한이 필요해요. Tidy는 정리할 때만,
One UI 홈 화면에서만 이 권한을 써요.

## 설치

1. [최신 릴리스](https://github.com/seolcu/tidy/releases/latest/download/tidy.apk)에서 `tidy.apk`를 내려받아요.
2. 파일을 열어요. Play 스토어 앱이 아니라서 처음 한 번은 브라우저나 파일 앱의 '출처를 알 수 없는 앱 설치'를 허용해야 해요.
3. 접근성 설정 → 설치된 앱 → **Tidy**를 켜요. 스위치가 회색이면 앱 정보 → ⋮ → 제한된 설정 허용을 누른 뒤 다시 켜요.
4. Tidy에서 **앱스 화면 읽고 정리하기**를 눌러요. 작업하는 동안에는 화면을 만지지 마세요.

새 버전은 GitHub에서 확인해서 앱 안에서 바로 업데이트할 수 있어요(설정 → 앱 업데이트).
